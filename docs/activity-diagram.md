# Activity Diagram Sistem Informasi SDM

Activity diagram dibuat dalam format native draw.io menggunakan tabel swimlane.

Buka file berikut menggunakan [diagrams.net](https://app.diagrams.net/) atau aplikasi draw.io:

- [activity-diagram-sdm.drawio](C:\laragon\www\contoh1\docs\activity-diagram-sdm.drawio)
- [activity-diagram-sdm-uml.drawio](C:\laragon\www\contoh1\docs\activity-diagram-sdm-uml.drawio) — versi dengan notasi UML Activity Diagram.

Swimlane yang digunakan:

- Pengguna
- Sistem Informasi SDM
- Database / Admin

Alur mencakup login, validasi akun, pengarahan berdasarkan role, aktivitas pengelolaan data SDM, pencatatan log aktivitas, dan logout.
