# Arsitektur Data

`users` menyimpan identitas login, `employees` menyimpan biodata, `employee_documents` menyimpan berkas, `specializations` menyimpan master kompetensi, `announcements` menyimpan siaran internal, dan `activity_logs` menyimpan jejak audit. Backup mengekspor snapshot JSON tabel-tabel tersebut ke ZIP.
