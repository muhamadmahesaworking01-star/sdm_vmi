# Dokumentasi Sistem SDM

## Gambaran Umum
Sistem ini adalah aplikasi web berbasis Laravel untuk mengelola data SDM dengan pendekatan berbasis role. Aplikasi mendukung beberapa peran pengguna, yaitu Super Admin, Direksi, Karyawan, Pengajar, dan Karyawan & Pengajar.

## Tujuan Sistem
- Mengelola akun pengguna dan hak akses berdasarkan role.
- Menyediakan dashboard yang berbeda untuk setiap role.
- Menyimpan data karyawan, pengajar, dan spesialisasi.
- Memudahkan monitoring profil, struktur organisasi, dan kompetensi.

## Aktor Utama
- Super Admin
- Direksi
- Karyawan
- Pengajar
- Karyawan & Pengajar

## Modul Utama
- Autentikasi dan manajemen akun
- Dashboard per role
- Data karyawan
- Data pengajar
- Master data spesialisasi
- Profil pribadi dan informasi tim

## Teknologi yang Digunakan
- Laravel
- Blade Template
- MySQL / Database relasional
- Bootstrap / Blade layout
